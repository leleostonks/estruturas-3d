Baixar para o SketchUp

  1. Escolha a medida no seletor abaixo do nome do modelo.
  2. Clique no ícone de download. O arquivo .skp baixa pronto para abrir.
  3. No SketchUp, use Arquivo › Abrir, ou arraste o .skp para dentro de um modelo aberto para inseri-lo como componente.

Cada barra vem como um grupo, separada por tipo (banzo, diagonal, pilar…), com etiqueta e material próprios. Os arquivos abrem no SketchUp 2017 ou mais novo.

Medidas personalizadas

  1. Clique no desenho do modelo para abrir a ficha.
  2. Em Personalizar medidas, ajuste vão, altura e módulos.
  3. Baixe em .dae e importe no SketchUp em Arquivo › Importar › COLLADA.

O .skp pronto existe para as medidas do catálogo. Medidas personalizadas saem em .dae, que o SketchUp importa com os mesmos grupos.

Adicionar estrutura

  • Use o card + Adicionar estrutura, sempre no fim da lista.
  • Aceita .dae (no SketchUp: Arquivo › Exportar › Modelo 3D › COLLADA), .dxf, .obj e .stl.
  • DXF com linhas de eixo vira estrutura de barras, com lista de materiais: cada camada vira um tipo de barra.
  • As estruturas adicionadas ficam em Minhas soluções, salvas neste navegador.

Outros formatos

  • .dae: SketchUp (Importar), Blender, 3ds Max.
  • .obj: Blender, Revit, Rhino.
  • .dxf: AutoCAD, FreeCAD, SAP2000. Linhas de eixo em camadas por tipo de barra.
  • .csv: lista de materiais para planilha, com perfil, metros e peso.

Pesos nominais de catálogo, sem ligações, chapas e parafusos. Servem para orçamento e não substituem o dimensionamento.
